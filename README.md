# FruitStealer (Unity)

Unity（C#）を用いて制作した、2Dスクロールアクションゲームです。

### タイトル
FruitStealer

### コンセプト
動物に奪われた果物を取り返す！

### コアメカニクス
縦オートスクロール型の2Dシューティング。敵の妨害を避けつつ、敵が落とした果物を拾い集めて投げつけ、敵を減速させて捕まえる。

### プレイ人数
1人

### 画面・進行システム
- 2D見下ろし型、縦オートスクロール進行。
- プレイヤーと敵は、基本的には一定の距離を保って平行移動している状態。

### 敵の行動・攻撃仕様
- プレイヤーの前方（画面上方）を等間隔で逃げ続ける。
- 後方に向かって障害物を落として妨害してくる。

### アイテム（果物）・弾の仕様
- プレイヤーは開始時に少量の果物（弾）を所持。
- 敵は妨害アイテムだけでなく、奪った果物も落とす。プレイヤーは果物を拾うことで弾を補充し、上に向かって撃ち出すことができる。

### システム・ペナルティ・勝敗条件
- **優勢（接近）：** プレイヤーの投げた果物が敵に命中すると、敵が減速し、プレイヤーとの距離が一定量縮まる。
- **ペナルティ（被弾）：** プレイヤーが障害物に当たると、一定時間動けなくなる。
- **クリア条件：** 制限時間内に、敵に果物を当て続けて距離を極限まで詰め、捕獲すればステージクリア。

## ソースコード
- **[Obstacle.cs](Assets/Scripts/Obstacle.cs) / [Bullet.cs](Assets/Scripts/Bullet.cs)**
    - 障害物や弾の動きの制御。Unityの物理演算に任せきりにするのではなく、数学の計算を使って制作。プレイヤーの横位置を追いかけ、特定の距離まで近づいたら真下に折れ曲がって落ちてくるという動きを実装。

- **[Enemy.cs](Assets/Scripts/Enemy.cs) / [GameManager.cs](Assets/Scripts/GameManager.cs)**
    - ゲーム全体の流れや、敵の動きを管理するコード。ゲームの進行状況に合わせて状態を切り替え、敵のスピードを4倍にしたり、行動パターンを弾を撃つものからジャンプへと変化させるモードを実装。
